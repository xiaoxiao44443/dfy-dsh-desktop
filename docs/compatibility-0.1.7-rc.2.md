# DSH 0.1.7-rc.2 适配

桌面端与开发运行时同步升级至 `0.1.7-rc.2`，Electron `43.4.0`、pnpm `11.19.0` 保持不变。

## 接入调整

- 审批通知优先使用官方 `displayReason` 和当前 `locale.resolveText()`，与审批卡片使用同一语言选择规则；保留旧运行时的 `reason` 回退，不修改审计内容或允许／拒绝的应答协议。
- 桌面桥接显式声明 `locale` 服务与客户端模块依赖，遵守 Cordis 服务注入约束。
- 缩小桌面壳的刷新快捷键拦截范围，放行 rc.2 的 `Ctrl/Cmd+Shift+R`（重命名会话）和 `Ctrl/Cmd+Alt+R`（刷新当前面板），继续防止普通 `Ctrl/Cmd+R` 与 F5 重载整个桌面壳。
- rc.2 的 `loadProfileDirectory()` 返回 `skippedBundles`，自身不再输出跳过日志；启动器调用 `reportSkippedBundles()`。桌面端使用官方启动器，原诊断解析仍适用。集成测试改为验证重复读取不输出、启动报告只输出一次，同时保留版本拒绝和启停验证。
- 上游审批界面新增可选 `shortcuts` 服务；测试环境允许该可选服务缺席，仍使用真实 `PendingApproval` 验证系统通知的一次性应答。

## 定时任务

保留官方默认值：`schedule`、`ui-schedule`、`time-context` 默认关闭，已有用户覆盖配置保持有效。启用后，提醒投递到原会话，任务和投递历史持久保存。

窗口关闭到托盘时 Harness 仍运行，提醒可以投递；彻底退出或休眠期间不能实时投递。任务运行记录表示提醒已进入会话收件箱，不表示模型工作完成。带活动提醒的会话须先停止活动再归档，取消归档不会重新创建提醒。

## 验证

- 桌面端类型检查、构建通过；63 个测试文件共 717 项通过、2 项跳过，其中包含真实 Electron 的关闭到托盘、关闭即退出测试。
- DFY 插件共 54 个导入接口检查通过；真实运行时的工具、审批、会话回放、原生消息桥接检查通过。
- 组合包在 rc.2 下完成启动、逐组件启停、整个组合包启停、独立安装迁移与配置保留验证。现有插件版本范围接受 rc.2，无需为范围校验单独发布插件。
- 在独立的开发配置和测试会话内启用定时任务，使用本地固定回复模型，未调用付费模型或读取真实会话。关闭到托盘后，单次提醒投递、模型回复和桌面通知均成功；任务运行记录可查看。
- 活动提醒阻止归档、停止后归档、取消归档不恢复任务均通过。
- 完整退出并重启隔离开发版后，两个测试任务和一次已保存的提醒投递记录均保留。
- 深浅色主题、标题栏同步、壁纸、开关和滑块可正常显示，壁纸菜单保持右对齐。
- 组合包中的图像生成、Codex 连接设置页正常；快捷键设置页正常。真实 Electron 按键验证 `Ctrl+Shift+R` 打开重命名窗口、`Ctrl+Alt+R` 到达 Harness，普通 `Ctrl+R` 仍被桌面壳拦截。

官方桌面端的首次使用引导、安装器和原生退出确认属于其独立外壳；本项目承载官方 Web profile，不自动继承这些原生实现。
