# DSH 0.2.0-rc.2 适配

桌面端版本、开发依赖与内置运行时同步至 `0.2.0-rc.2`。Electron 保持 `43.4.0`，内置 pnpm 保持 `11.19.0`；最低 DSH 版本仍为 `0.1.7-alpha.1`。

## 接入范围

- 升级官方 npm 包和锁文件，沿用现有 `runCli()` 启动入口、模块解析与桌面桥接。本次检查未发现需要额外修改桌面端接入代码或 DFY 插件接口的地方。
- 新版 Harness 包含模型选择器搜索、计划审阅修复、聊天过程和深色主题样式调整，以及持久 PowerShell 命令完成识别修复。
- 上游同时更新了 pi-ai 模型目录。以新版适配器只读校验本机现有的五个自定义模型，模型解析和推理等级解析均通过，没有修改用户模型配置，也没有调用模型接口。
- 官方桌面端的命令安装菜单、登录 shell 环境加载和包内 Node 签名调整属于其 Electron 桌面实现，不因升级本项目承载的 Web profile 而自动接入。
- 实验性异步问答保持官方默认设置，不自动开启。
- 桌面端安装包下载新增 GitHub 直连与三个公共代理的自动测速、最快线路选择、下载速度显示和失败切换。版本与摘要继续从 GitHub 获取，完整文件通过大小和 SHA-256 校验后才进入可安装状态；没有改动 DSH 的 npm 更新源。

## 验证

- 主进程与渲染进程类型检查、前后端构建通过。
- 桌面端回归测试：62 个测试文件通过、1 个跳过；714 项通过、5 项跳过。包含真实 DSH 插件启停网关及兼容性拒绝检查；本次未启用原生托盘窗口测试。
- 在隔离 DSH Home 中，DFY 组合包八个插件完成真实启动、逐项启停、整包启停，以及从独立安装迁移后配置、数据和禁用状态保留验证。未读取或改写日常会话。
- 已准备 macOS Intel 的内置运行时目录与归档。使用 Electron `43.4.0` 的内置 Node 加载 `koffi`、`node-pty` 成功；通过桌面启动器执行内置 `dsh --version`，返回 `0.2.0-rc.2`。
- 新增下载功能后，下载器、桌面更新和窗口控制相关的 98 项测试通过，类型检查和前后端构建通过。覆盖分段测速、缓存、测速超时、下载停滞、错误内容、摘要不符、备用线路重试、本地文件错误，以及更新面板的状态传递。
- 用新下载器对已发布的真实安装包进行了四路各最多 512 KiB、8 秒时限的探测，未完成采样的线路被排除，没有下载完整安装包。首次测试使用旧域名，现将该线路改为直接使用 `gh-proxy.com`。

本次仅构建代码和内置运行时，没有生成桌面安装包、替换已安装 App 或发布 Release。Windows 与 macOS Apple Silicon 的原生运行时仍需在对应平台构建验证。

参考：[官方更新说明](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.0-rc.2)。
