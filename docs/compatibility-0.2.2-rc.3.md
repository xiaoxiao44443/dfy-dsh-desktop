# DSH 0.2.2-rc.3 适配

桌面端版本、开发依赖与内置运行时从 `0.2.1-rc.3` 升级至 `0.2.2-rc.3`。Electron 保持 `43.4.0`，pnpm 保持 `11.19.0`。已生成 Windows x64 生产运行时与 `build/harness-runtime.tgz`。

## 官方菜单与桌面浏览器

- 文件与网页菜单使用官方 `contextMenus` 服务，包括鼠标右键和键盘触发；外观插件在有该服务时停用原先的文件菜单。
- 桌面浏览器仅增加“在内置浏览器中打开”操作，支持 HTTP(S) 网址以及本地 HTML、HTM、XHTML。官方的复制、下载、默认程序打开、显示位置等操作继续由官方提供。
- 文件路径通过菜单目标中捕获的会话解析，不读取可能已变化的当前窗口或文字标签。请求取消后不再提供过期操作；中文、空格和 `#` 文件名经实际开发版验证。
- 新增的浏览器打开路由使用现有鉴权桥接，限制地址格式与协议；浏览器关闭时返回明确错误。旧 DSH 没有统一菜单服务时，浏览器原有功能仍可加载。

## 配套插件

- **外观**：使用官方统一菜单，保留行距和已有外观设置；不恢复过程折叠或重复字号功能。
- **Codex 连接**：适配批量工具执行、条件工具列表、原生/PTC 执行器选择及不同程序格式，保留审批、取消、调用方身份和子工具结果；程序最终失败时不误报子工具成功。
- **媒体内容**：适配新版上传回执的 image/file 类型，保留官方准入、图片降级、普通文件和重复请求去重。
- 实际组合包组件启停和原配置保留检查通过。包更新能力字段的变化不影响现有桌面插件管理路径，其余维护中插件没有发现必须修改的接口问题。视觉理解插件继续停用。

插件仓库保留原开发基线，通过能力检测兼容新旧接口。本轮配套版本为外观 `0.1.8`、Codex 连接 `0.1.4`、媒体内容 `0.1.6` 与组合包 `0.1.4`；升级桌面端后需在插件管理中同步更新。

## 实验性 Agent 可见终端

官方的新功能允许 Agent 在会话侧栏创建持续运行的终端，例如运行开发服务器或监听任务；用户可以查看输出并接管输入，接管后 Agent 只能读取输出。

Windows 沙箱启动该终端时，官方需要经 ConPTY 启动 ACL 辅助进程，与桌面端复用 Electron 作为 Node 的方案存在兼容问题。本轮按用户选择保留现有运行时方案，暂不支持这条实验性路径。启动器会在创建该辅助进程前给出清晰错误，不让它变成无输出的等待，也不降低沙箱权限。

普通手动内置终端和原有命令执行工具不走这个受限路径，仍可使用。此防护只在 Windows Electron 运行时生效；没有修改用户的 Agent 预设或官方实验性插件配置。macOS 未进行本机验证，不能据此承诺该实验功能可用。
