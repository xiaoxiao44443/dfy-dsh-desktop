# DSH 0.2.1-rc.2 适配

桌面端版本、开发依赖与内置运行时同步至 `0.2.1-rc.2`。Electron 保持 `43.4.0`，pnpm 保持 `11.19.0`。本轮检查包含从 `0.2.0-rc.2` 到 `0.2.1-rc.2` 的累计变化。

## 桌面接入

- 沿用官方 `runCli()`、独立 Harness 子进程和 Web profile，不修改官方运行时。已准备 Windows x64 生产依赖目录及 `build/harness-runtime.tgz`。
- 新版插件兼容性结果及启动警告使用 `requirements`，其中可以包含 `engines.dsh`；桌面端识别并显示对应插件、组合包、当前版本和要求范围，同时兼容旧 `peers` / `peerDependencies` 格式。
- 官方主题服务新增正文、代码和终端字体/字号，并自行处理并发保存时的过期响应。桌面桥接在新版不再接管主题 adoption 和 `form.set` 排序，只处理断线时 `form.mutate` 的拒绝与恢复。标题栏继续使用官方主题事件即时同步。旧运行时保留原防回跳逻辑。
- 新版 API Gateway 的客户端入口拆为 browser/node，测试夹具按包的实际 `exports` 选择入口。会话持久化和插件清单测试也随官方导出、不可读包的处理方式调整，保留原有验证目标。
- 官方自动化任务进入 Web 默认组成；页面可正常打开。官方桌面版的窗口、安装器、字号快捷键、账号集成等专属改动不会仅因更新本项目的 Web runtime 而自动接入。
- 适配 Web 账号登录先 `window.open('about:blank')`、再异步跳转授权链接的流程。桌面端保留不可见且不带桌面 preload 的临时窗口，收到 HTTP(S) 授权链接后阻止窗口内导航并交给系统默认浏览器；取消、窗口关闭或等待超时会清理占位窗口。普通外部链接继续直接使用默认浏览器。

## 插件适配与功能重叠

| 插件或功能 | 处理 |
| --- | --- |
| 外观的对话字号 | 按用户选择改用官方设置。新 DSH 隐藏重复滑块及字号 CSS 覆盖，保留行距、生成内容位置和文件右键菜单；旧 DSH 保留旧控制，已有配置不覆盖官方偏好。 |
| 媒体内容 | 移除对已下线 `projectUserText` 具名导出的依赖。新 DSH 复用官方用户内容 Factory，历史 DFY 图片走原资源接口；文本遮挡、引用和有序附件交给官方渲染。 |
| 媒体发送适配 | 包装方法保留每次 Gateway 调用的接收对象及调用方身份，避免原调用和图片降级路径丢失授权上下文；并发等待队列不会串用身份。仍只扩展官方图片能力拒绝，不放宽其他校验。 |
| 壁纸 | 保留分区域背景、遮罩和透明度功能，与官方主题设置共存。 |
| 归档管理 | 官方已有归档操作，本插件提供按项目集中管理、恢复和批量删除，保留。 |
| 图像生成 | 保留独立生图路由和参考图编辑；官方图片输入和预览不替代模型调用。 |
| 交互可视化 | 官方 HTML 文档预览与其部分用途重叠；本插件仍负责会话级产物存储和对话内交互，保留。 |
| 任务守卫 | 保留重复调用检测和单轮预算。长任务可能先被其硬预算停止，按需求调阈值或只提醒；不自动改变用户策略。 |
| Codex 连接 | 官方 Codex 子智能体是 DSH 调用 Codex；现有桥接是 Codex 调用 DSH，方向不同，保留。 |
| 视觉理解 | 继续停用维护及发布，不恢复已撤回的插件。 |

官方已经提供工作步骤折叠设置，外观插件不会重新实现。官方自定义插件索引与桌面 DFY 目录存在入口重叠，但桌面端还提供组合包迁移、防混装和本地来源管理，本轮不删除。

插件范围声明不必全部改写：官方优先检查 `engines.dsh`，未声明时仍使用 DSH 相关 peer 范围。组合包的现有声明已通过真实新版运行时检查。未发现维护中的插件使用已移除的 `./invariant` 导出或替换旧 composer `stats` 插槽。

## 验证记录

- 桌面端类型检查与前后端构建通过；回归测试 64 文件通过、1 文件跳过，745 项通过、4 项跳过。
- 插件全仓构建、类型检查、132 项测试通过；实际运行时的 53 个具名导出检查无缺失。命名空间兼容分支另由行为测试及界面验证覆盖。
- 实际 AgentLoop、ToolRuntime、审批允许/拒绝/取消、FIFO、会话日志重放、SessionController 图片降级及并发调用方身份检查通过，未请求真实模型。
- 隔离 DSH Home 中，独立安装迁移到组合包、8 个组件逐项启停、整包启停及配置/资源/禁用选择保留检查通过。
- Windows Electron 开发版实际验证：暗色主题与重启恢复、正文 14→20 和代码独立字号、自动化任务页、内置浏览器新空白标签自动聚焦地址栏。
- 历史 DFY 媒体消息显示图片和文件成功，测试密钥经官方文本规则遮挡。外观和媒体客户端保持页面打开，在构建监听运行时修改可见文案并还原；各自始终只有一个样式节点，文件输入保持隐藏。停用后自有样式和 DOM 清空，启用后恢复。
- 生产运行时通过 Electron 内置 Node 24.18.1 与桌面启动器执行 `dsh --version`，返回 `0.2.1-rc.2`；`koffi` 和 `node-pty` 原生依赖加载成功。
- 登录窗口专项回归及关联测试 99 项通过。隔离 Electron 运行官方 `BrowserLogin`，复现原空白窗口被拒问题，并验证异步转交授权链接、不加载内嵌登录页、不继承桌面 preload、取消和父窗口关闭清理；测试替代系统浏览器调用，未登录真实账号。

测试使用临时配置与会话，没有迁移日常 DSH 数据、修改真实模型配置或替换安装版。已生成本地 Windows x64 安装包。本次适配的配套插件为外观 0.1.7、媒体内容 0.1.5、组合包 0.1.3；只升级桌面运行时不会自动更新已安装的插件。macOS 原生运行时和真实模型请求未在本机验证。
