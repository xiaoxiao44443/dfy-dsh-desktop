# DSH 0.2.1-rc.3 适配

桌面端版本、开发依赖与内置运行时从 `0.2.1-rc.2` 同步升级至 `0.2.1-rc.3`。Electron 保持 `43.4.0`，pnpm 保持 `11.19.0`。已重新生成 Windows x64 生产运行时及 `build/harness-runtime.tgz`。

## 上游变化与接入检查

- 官方 Web profile 新增导航入口定制插件，为左侧栏、会话视图和右侧栏提供“更多”菜单，支持入口固定、浏览插件及创建插件草稿。升级后由官方配置直接加载，桌面壳不另行注入重复入口。
- 新的菜单通过新增 actions 插槽和可选参数扩展现有接口。现有桌面桥接和 DFY 插件未替换受影响的侧栏根组件或会话标题组件；现有 `Menu` 的 `align: 'end'` 调用仍兼容。
- 官方修复新会话与未发送草稿的恢复逻辑，新增 `whenDraftExists`，保留旧 `clearPreviousDraft` 的兼容行为；桌面层无需接管草稿。
- DeepSeek API Key 路由在官方 API 地址、内置模型目录条件下使用 `/models` 同步列表。自定义地址或显式自定义模型目录仍保留配置行为；桌面端无需改写用户提供方配置。
- CLI、桌面插件解析、主题事件及账号登录转交沿用 rc.2 接入。此次未发现需要新增桌面业务兼容补丁的问题。

## 配套插件

使用现有外观 `0.1.7`、媒体内容 `0.1.5` 与组合包 `0.1.3` 检查，未发现本轮必须修改或重新发布插件的兼容问题。官方新增导航菜单不替代壁纸、外观行距、媒体资源、图像生成、交互可视化和 Codex 连接等能力。

视觉理解插件继续停止维护与发布。此前已移除的过程折叠和重复字号功能不恢复。历史功能重叠与版本范围说明见 [rc.2 适配记录](compatibility-0.2.1-rc.2.md)。

## 验证记录

- 桌面端类型检查、主进程及 renderer 构建通过；64 个测试文件通过、1 个跳过，745 项测试通过、4 项跳过。
- 配套插件针对实际 rc.3 运行时的 53 个具名导出检查通过；AgentLoop、审批允许/拒绝/取消、FIFO、会话日志重放、ToolRuntime、媒体降级和并发调用方身份回归通过。
- 隔离配置中的独立插件迁移至组合包、8 个组件唯一装配、逐项启停、整包重启及原配置和禁用选择保留验证通过。
- 使用 Electron 内置 Node `24.18.1` 加载生产运行时的 `koffi`、`node-pty` 成功，桌面启动器执行 `dsh --version` 返回 `0.2.1-rc.3`。
- 隔离 Web profile 通过桌面启动器启动成功，令牌换取 Cookie 后返回 HTTP 200 与官方前端页面；测试结束后已关闭进程。
- 隔离 Electron 运行 rc.3 官方 `BrowserLogin`，验证隐藏占位窗口、异步授权地址转交、无桌面 preload、无内嵌授权请求、取消和父窗口关闭清理。系统浏览器启动由测试替身记录，未登录真实账号。
- 已生成本地 Windows x64 NSIS 安装包 `DFY-DSH-Desktop-0.2.1-rc.3-x64.exe` 和独立 SHA-256 校验文件。包内桌面版本为 `0.2.1-rc.3`，运行时归档摘要与已验证的生产归档一致；打包后的 Electron 可加载原生依赖，并经 `app.asar` 中的桌面启动器执行 `dsh --version`，返回 `0.2.1-rc.3`。

验证未修改日常 DSH 配置或请求真实模型。本轮未进行完整可见界面的逐项操作、macOS 本机验证或安装向导实装；上述检查不等同于所有插件界面行为的完整认证。
