# 换设备继续开发：DSH 0.1.7-alpha.1 与组合包

用户要求暂停验证、提交推送当前改动，不打桌面包、不发布 Release。

## 已完成

- 内置 DSH / 桌面版本升级到 0.1.7-alpha.1，最低可选 DSH 同步调整；Electron 保持 43.4.0。
- 运行时 Node internals、旧会话格式迁移、通知及插件 API 适配。
- 标题栏跟随 DSH 当前明暗选择；右侧壁纸容器修复在插件仓库。
- 插件总开关对接官方管理器，清理旧 disabledBundles / bundleOrder，更新包时保留禁用选择。
- 组合包目录展示、实际组件版本读取、防止组件重复安装及批量选择去重已实现。

## 已有验证

- 组合包改动前：桌面全套测试 658 项通过、2 项跳过（需监听端口的 3 项在沙箱外单独补跑通过）；实际官方管理器的 HMR 与非 HMR 启停测试通过。
- 组合包相关：类型检查通过，原插件管理 29 项测试及新增组合包 5 项测试通过。
- 组合包之前的开发版已启动并确认官方插件页面正常。组合包改动之后尚未重新构建主进程及做桌面界面验收。

## 待继续

- 插件仓库已新增 `@dfy-plugins/dsh-bundle@0.1.0`，尚未发布 npm。
- 目前开发中的桌面备用目录含组合包，远程正式 catalog.json 尚不包含；用插件仓库的 catalog.preview.json 配合 `DFY_PLUGIN_CATALOG_FILE` 预览。
- 用户真实 web Profile 尚未从 8 个单独本地链接迁移。组合包安装、旧安装迁移、包内条目启停和 UI 验收仍需完成。
- 当前管理页管理整包；内部开关在 DSH 官方插件详情页。DFY 目录将内含插件标为组合包提供，并跳转整包管理。
- 已有单独安装时会阻止混装，尚未实现自动迁移按钮；组合包缺失组件的修复体验也应在实机检查。
- 新增 `test/fixtures/plugin-activation-017.mjs` 和 `history-migration-017.mjs` 使用实际 DSH 运行时；运行说明在文件头与测试中。

配套细节见插件仓库 `docs/development-handoff-2026-09-22.md`。不要触发 v* 或 npm-* 标签发布，等待用户继续安排。
